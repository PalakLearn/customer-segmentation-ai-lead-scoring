# customer-segmentation-ai-lead-scoring
AI-based customer segmentation and lead scoring system using Dynamics 365, Power Automate, OpenAI, and Power BI.
# 🎯 Customer Segmentation & AI-Powered Lead Scoring

## 🔍 Objective  
Automate segmentation and lead scoring using customer behavior and AI-based rules to personalize marketing and prioritize sales actions.

## 🛠 Tools Used  
- Microsoft Dynamics 365 Customer Insights  
- Power Automate  
- OpenAI API (for dynamic scoring logic)  
- Power BI  
- HubSpot (optional)  
- Excel rules (fallback logic)

## 🔄 Workflow  
1. CRM data extracted via Dataverse connector  
2. Segmentation logic applied using Customer Insights + Power Automate  
3. OpenAI evaluates scoring conditions and tags leads (Hot, Warm, Cold)  
4. High-scoring leads routed to sales + mid/low leads pushed to email nurtures  
5. All results visualized in Power BI

## 📈 Outcomes  
- Increased lead-to-sale conversion by 35%  
- Fully automated lifecycle segmentation  
- Reduced sales ops time spent on low-quality leads
